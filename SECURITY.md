# Security policy

This is a public **sanitized case-study repository**, not a production deployment.

Do not post vulnerabilities containing confidential data as public issues. Use GitHub private vulnerability reporting if available, or contact the repository owner through a private channel.

No private source code, secrets, credentials, production configuration, real alert logs or operational network identifiers should be contributed. All additions need manual review before merging. A `.gitignore` does not remove sensitive content from Git history.
