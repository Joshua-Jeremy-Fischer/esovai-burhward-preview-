# Limitations

This public repository is a **documentation and portfolio showcase**, not a deployed SOC or independently audited security product.

The private engineering effort has documented open integration topics, including:
- Bridge-side integration and operational execution flows
- Production loader and verifier
- Role-binding and revocation enforcement
- Step-up authentication enforcement
- Executor outcome audit integration

Some functionality in the architectural model is planned or partially integrated. The public case study must not be used as proof of production readiness. The showcase intentionally excludes real credentials, original private history, infrastructure details and operational logs.
