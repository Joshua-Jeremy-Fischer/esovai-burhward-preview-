# Example: SIEM alert case study

> **Illustrative scenario only** — this is not a reproduced live scan.

## 1. Detection / Recon context
A SIEM raises a synthetic alert indicating repeated failed authentication attempts from a placeholder source. Capture alert type, timestamps, relevant evidence and confidence limitations. Never publish actual IPs or identities.

## 2. Analysis
Normalize the event, classify through defined rules, and optionally provide an AI-supported explanation. Distinguish observed evidence from a generated hypothesis.

## 3. Proposed response
Display an action preview showing what an analyst would approve, reject, or escalate.

## 4. Human decision
Require relevant approval and enforce that a proposal is not executed solely because a model recommended it.

## 5. Verification and reporting
If execution is supported and authorized, verify its actual outcome. Record decision, policy context and result.
